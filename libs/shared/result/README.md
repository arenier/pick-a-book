# shared-result

Type `Result<T, E>`, pour rendre l'echec explicite dans les signatures.

Lib partagee au sens de l'ADR 0002 : technique et generique, sans metier dedans. Elle n'importe
aucun contexte — la dependance ne va jamais dans ce sens.

## Commandes

```bash
yarn nx test shared-result
yarn nx lint shared-result
yarn nx build shared-result
```
